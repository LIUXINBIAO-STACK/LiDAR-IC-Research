# LiDAR-IC-Research

**激光雷达（LiDAR）电源管理与高速激光驱动前期调研仓库**

> **当前阶段**：前期技术调研与基础学习阶段（具体立项题目、细分切入点及硬件指标待与导师及课题组师兄进一步交流后最终确定）。

## 仓库简介

本仓库用于记录团队围绕激光雷达发射端（dToF LiDAR）开展的 **前期知识积累、文献与芯片手册调研及系统架构探索**。当前研究围绕两大基础方向并行推进：

- **电源管理方向（`02_Power_Management`）**：系统学习 Buck、Boost、LDO 基本原理与组合架构、脉冲负载下的储能电容选型（ESR/ESL 与充放电平衡）及低纹波供电设计。
- **激光驱动方向（`03_Laser_Driver`）**：系统学习激光二极管（LD）光电特性、常见驱动拓扑（恒流 / 方波开关 / 电容放电）、纳秒级脉冲时序与六大关键性能指标、MOSFET/GaN 栅极驱动、RLC 阻尼控制及典型高速驱动芯片手册拆解。

## 拟探讨的候选方向（待与课题组讨论确定）

基于当前调研，团队初步梳理出以下值得进一步论证的结合点，待组会讨论收敛：

1. **脉冲电源与高速驱动协同设计**：探索动态升压供电、储能电容满充控制或开关电源噪声抑制，以提升高重频发射时的脉冲幅值一致性与时间稳定性。
2. **高速 GaN 窄脉冲驱动与抗振铃优化**：结合低寄生电感 PCB 布局、开尔文源极回流与栅极阻尼控制，研究纳秒级大电流脉冲的过冲抑制与安全保护机制。
